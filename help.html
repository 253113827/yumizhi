常见问题

什么是 yumizhi (玉米知)?

yumizhi (玉米知) 是一个专注于收集和整理 OpenClaw 技能的平台。我们汇集了超过 1700 个社区贡献的 AI 技能，涵盖 Web 开发、AI 代理、Git 管理、系统运维等多个领域，帮助用户发现和使用这些强大的工具。

如何使用平台上的技能?

要使用平台上的技能，您需要首先安装 OpenClaw 框架。然后，可以通过点击技能详情页面的链接访问技能的完整文档和安装说明。每个技能都有详细的使用指南和示例代码，帮助您快速上手。

如何添加新的技能?

我们欢迎社区贡献新的技能！您可以通过 GitHub 提交 Pull Request，按照我们的技能标准格式创建新的技能文档。我们有详细的贡献指南，包括技能命名、描述、分类等规范。所有提交的技能都会经过社区审核后添加到平台。

如何收藏我喜欢的技能?

登录后，您可以在技能详情页面点击收藏按钮来收藏技能。收藏的技能会保存在您的个人中心，方便以后快速查找和使用。您也可以在个人中心管理您的收藏列表。

如何给技能评分和评论?

登录后，您可以在技能详情页面看到评分和评论功能。点击评分按钮可以给技能打分，撰写评论可以分享您的使用体验。这些反馈对其他用户很有帮助，也能促进技能的持续改进。

如何联系技术支持?

如果您遇到问题，可以先查看常见问题或使用搜索功能。如果仍未解决，可以通过下方的联系方式与我们取得联系。我们的技术团队会在工作时间内尽快回复您的问题。
