## OKX API配置信息

- **环境变量**:
  - `OKX_API_KEY`: API密钥
  - `OKX_SECRET`: API密钥对应的密钥
  - `OKX_PASSPHRASE`: API密钥的密码短语

- **查询余额命令格式**:
  ```bash
  curl -s "https://www.okx.com/api/v5/account/balance" \
    -H "OK-ACCESS-KEY: ${OKX_API_KEY}" \
    -H "OK-ACCESS-SIGN: ${SIGNATURE}" \
    -H "OK-ACCESS-TIMESTAMP: ${TIMESTAMP}" \
    -H "OK-ACCESS-PASSPHRASE: ${OKX_PASSPHRASE}" | jq '.data[0].details[] | select(.cashBal != "0") | {ccy: .ccy, cashBal: .cashBal, availBal: .availBal}'
  ```
